在系統思考（Systems Thinking）以及認知心理學中， **System 1（系統一）與 System 2（系統二）** 是由諾貝爾經濟學獎得主丹尼爾-康納曼（Daniel Kahneman）在其著作《快思慢想》（*Thinking, Fast and Slow*）中提出的經典大腦認知運作模型。

這兩個系統共同形塑了人類如何感知世界、做出決策以及面對複雜系統時的反直覺反應。以下為兩者的核心定義與對比：

### 核心定義

-   **System 1（系統一：直覺思考 / 快思）**
        -   **定義**：大腦 **自動化、下意識且快速** 運行的思考模式。它不需要耗費多少精力，也沒有自主控制的感覺。
        -   **運作機制**：依賴經驗、直覺、情感與情緒（Heuristics）。它能幫我們在瞬間對環境做出反應（例如：看到一隻狗在吠叫立刻退後、解開簡單的數學 1+1=2）。
-   **System 2（系統二：邏輯思考 / 慢想）**
        -   **定義**：大腦 **需要耗費精力、專注且緩慢** 運行的思考模式。它與人的自主意識、選擇、邏輯和專注度密切相關。
        -   **運作機制**：需要調動大腦的認知資源（Cognitive Resource）。它負責處理複雜的因果關係、數據分析、長遠規劃與理性決策（例如：在吵雜的房間裡專注聽某人的聲音、計算 17 × 24 的答案）。

### 直觀對比表

| 特性 | System 1 (快思) | System 2 (慢想) |
| :-- |  :-- |  :-- |
| **速度** | 極快（毫秒級） | 緩慢（秒到分鐘級） |
| **精力消耗** | 極低（幾乎不費力） | 高（容易感到大腦疲勞） |
| **運作狀態** | 持續在背景運行、不間斷 | 預省電狀態，需要被「喚醒」 |
| **控制權** | 不受意志控制（自發性） | 受意志控制（自覺性） |
| **思考本質** | 直覺、情感、經驗、聯想 | 邏輯、理性、數據、批判 |

### 在「系統思考」中的關鍵意義

在解決複雜的組織、社會或生態系統問題時，理解 System 1 與 System 2 的限制至關重要：

-   **「反直覺」的系統特性**：複雜系統（Complex Systems）往往具有延遲性（Delays）與非線性（Non-linear）的特質。如果我們只依賴 **System 1 的直覺**去解決問題，往往會直覺地採用「頭痛醫頭、腳痛醫腳」的頭標式解法，進而落入「對症下藥，但副作用更大」的系統基模（Archetypes）陷阱中。
-   **必須刻意啟動 System 2**：要看清整個系統的全局，我們必須刻意壓抑 System 1 的直覺衝動，調動 **System 2 的理性分析**，畫出系統環路圖（Causal Loop Diagrams），找出時間延遲與隱藏的動態反饋，才能找到真正具備槓桿效益（Leverage Point）的根本解。
