## TCExam 技術簡介

### 概述

TCExam 是一個基於網路的 **電腦化評量（Computer-Based Assessment, CBA）** 軟體，由 Nicola Asuni 開發，自 2004 年以來持續進化。該軟體旨在簡化學校、大學、招聘機構以及公私部門的評量流程。

### 主要用途

#### 1. 考試與測驗管理
- 創建、分發和管理考試、測試、問卷和問答題
- 支援線上考試和紙上考試兩種模式
- 自動評分和結果統計分析

#### 2. 問卷調查
- 創建和管理問卷調查
- 收集和分析回答數據
- 生成統計報告

#### 3. 認證與測驗
- 提供認證考試解決方案
- 支援多種認證類型
- 管理認證流程

### 常見應用情境

#### 教育機構
- **大學與研究所**：課程考試、期末考、資格認證考試
- **高中與小學**：日常測驗、期中考、期末考
- **線上課程平台**：與學習管理系統整合

#### 企業與組織
- **招聘與人才評估**：職位候選人能力測試
- **員工培訓與考核**：內部技能評量
- **專業認證考試**：行業資格認證

#### 研究機構
- **學術研究**：心理學、教育學研究工具
- **數據收集**：大型問卷調查
- **實驗設計**：控制變量的研究環境

#### 政府機關
- **公務人員考試**：公開競爭性考試
- **專業資格認證**：職業技能認證
- **社會福利評估**：資格審核流程

### 主要技術特性

#### 技術架構
- **語言**：PHP 8.2+（支援 8.2/8.3/8.4）
- **資料庫**：MySQL/MariaDB、PostgreSQL、Oracle
- **網頁伺服器**：Apache（推薦，搭配 mod_php）
- **架構**：LAMP 堆疊（Linux + Apache + MySQL + PHP）

#### 關鍵功能

##### 靈活性與配置性
- 高度可自訂的配置選項
- 適應多種使用場景
- 模組化設計，易於擴展

##### 自由開放軟體
- 採用 **GNU AGPLv3** 開源授權
- 社群驅動開發模式
- 獨立同行審查

##### 國際化支援
- 支援 26 種語言翻譯
- UTF-8 編碼，Unicode 標準
- 右至左語言支援（阿拉伯語、希伯來語）

##### 無障礙設計
- 遵循 WCAG 2.1 Level AA 標準
- 語義化 HTML5
- ARIA 角色標記
- 螢幕閱讀器友善設計

##### 結果與統計分析
- 多樣化的結果頁面輸出
- 多種篩選條件
- 統計指數分析
- 結果導出多種格式（TSV、XML、PDF）

##### 數據進出支援
- TSV、XML、PDF 標準格式
- OMR（光學標記識別）掃描紙張答案卡
- LDAP、RADIUS、CAS 單點登入

##### 多媒體內容
- 支援 LaTeX 和 MathML 數學公式
- 圖片與多媒體物件
- 統一的標記語言處理

##### 獨特試卷生成
- 隨機選擇和排序題目
- 為不同使用者生成獨特試卷
- 降低作弊風險

##### 紙上考試支援
- 生成可列印的 PDF 考試文件
- OMR 答案卡自動識別
- 紙上考試數位化評分

### 測試方法

#### 單元測試
```bash
## 執行純邏輯單元測試（不需資料庫）
make test

## 或使用 phpunit 直接執行
php vendor/bin/phpunit test/
```

#### 整合測試
```bash
## 使用 Docker 執行整合測試（推薦）
make dockertest

## 指定資料庫類型
make dockertest DB_TYPE=postgres

## 完整的測試套件
make qa
```

#### 測試流程

```bash

composer install

## 執行測試
make test
```

##### 2. 整合測試環境

### 安全性考慮

#### 基本安全措施
1. **修改預設密碼**：立即更改 admin 預設密碼
2. **刪除 install/ 目錄**：完成安裝後移除安裝文件
3. **權限管理**：設定適當的檔案系統權限
4. **HTTPS**：使用 SSL/TLS 加密傳輸
5. **防火牆**：限制不必要的端口開放

#### 常見安全問題
- SQL 注入防護（使用參數化查詢）
- XSS 防護（輸出編碼）
- CSRF 防護（使用 token）
- 密鑰硬編碼避免（使用環境變數）

### 已知問題與限制

#### 已知問題
1. **PDF 字體生成**：首次安裝需要時間生成字體
2. **大規模數據庫**：超過 100,000 題目的查詢可能較慢
3. **舊瀏覽器相容性**：IE 11 及以下版本相容性較差
